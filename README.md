# Specialty-Coffee-E-commerce
الفكرة: منصة تسوق إلكتروني متكاملة تعرض أدوات القهوة (أقماع تقطير، مطاحن، موازين، حبوب قهوة) مع نظام سلة تسوق وإتمام طلب.  الأقسام الرئيسية:  صفحة المنتجات: فلترة حسب النوع (أدوات، حبوب)، السعر، والتقييم.  سلة التسوق وإتمام الطلب (Checkout): محاكاة لعملية الدفع وإدارة الطلبات.  لوحة تحكم المدير: لإضافة منتجات جديدة، تعديل المخزون، ومتابعة الطلبات.
